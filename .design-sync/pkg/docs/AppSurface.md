The root of every Fightlytics screen: the off-black `--bg-base` page with `--text-primary` ink. The product is dark-only, and every component assumes this background, so wrap a design's top level in `<AppSurface>`. `padding` (px, default 24; use 0 for a full-bleed layout) and `style` are optional.
